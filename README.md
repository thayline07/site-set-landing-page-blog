## 🧠 Sobre o projeto

O **Site.set** foi desenvolvido com o objetivo de praticar a construção de aplicações modernas utilizando Next.js, explorando conceitos como renderização híbrida, organização de conteúdo e componentização.

A aplicação combina:

- uma landing page institucional  
- um sistema de blog  
- renderização dinâmica de conteúdo  

---

## ✨ Funcionalidades

- Página inicial (landing page)
- Sistema de blog com Markdown
- Renderização de conteúdo com SEO
- Layout responsivo
- Componentização com React
- Navegação otimizada

---

## 🛠️ Tecnologias utilizadas

- Next.js  
- React  
- TypeScript  
- Tailwind CSS  
- Contentlayer  
- React Markdown  
- Remark GFM  
- Lucide React  

---

## ⚙️ Como funciona o blog

Os posts são escritos em arquivos Markdown e processados pelo Contentlayer.

---

Fluxo:

Markdown → Contentlayer → Next.js → Página renderizada
